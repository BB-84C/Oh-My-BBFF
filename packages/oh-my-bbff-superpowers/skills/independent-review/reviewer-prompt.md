# Reviewer Prompt Template

Review the supplied requirement, diff, and relevant evidence read-only. Report
only material semantic, risk, or integration findings, plus limitations that
prevent a conclusion. Do not manufacture style findings, a fixed issue quota, or
a worktree fallback when the supplied evidence is sufficient.

For each material finding provide the affected boundary, evidence, impact, and a
clear next action. If evidence is missing, name the limitation rather than
guessing. End with a concise assessment of whether the reviewed behavior is ready
for its stated acceptance boundary.
